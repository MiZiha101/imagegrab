# 图提取 ImageGrab

一款 **Chrome / Edge 浏览器插件**，帮你在电商商品详情页里，一键把所有商品图找出来，勾选后批量下载，并统一保存成 **PNG** 图片。

支持平台：

- 淘宝 / 天猫
- 京东
- 拼多多商家版

适合做什么：保存商品主图、详情长图、做素材整理、对比竞品图等。  
不适合：下载整个网页、在首页/搜索列表页抓图（插件只在「商品详情页」出现）。

> 所有图片都在你自己的电脑里处理，**不会上传到任何服务器**，也不需要登录账号。

---

## 目录结构

拿到插件文件夹后，大致是这样（不用改里面的文件，知道有这些就行）：

```
imagegrab/
├── manifest.json      # 插件的「身份证」，安装时浏览器会读它
├── content.js         # 在商品页右下角显示「获取图片」按钮，并扫描图片
├── content.css        # 按钮的外观样式
├── background.js      # 后台干活：打开预览页、转成 PNG、批量下载
├── gallery.html       # 预览勾选页面（新标签页）
├── gallery.js         # 预览页的勾选、筛选、下载逻辑
├── gallery.css        # 预览页样式
├── icons/             # 插件图标
├── docs/              # 官网介绍页（双击 docs/index.html 就能看）
└── README.md          # 就是你正在看的这份说明
```

安装时请选择**整个 `imagegrab` 文件夹**（里面要能看到 `manifest.json`），不要只选某一个子文件夹。

## 插件安装步骤

大约 1 分钟。以 Chrome 为例（Edge 几乎一样，只是地址不同）。

### 准备工作

1. 把插件文件夹放到电脑里一个**固定位置**（例如 `D:\extensions\imagegrab`）。
2. 安装完成后，**不要随便移动或删除**这个文件夹，否则插件会失效。

### 正式安装

1. 打开 Chrome 浏览器。
2. 在地址栏输入下面这一行，然后按回车：

   ```
   chrome://extensions
   ```

   > Edge 用户请输入：`edge://extensions`

3. 打开页面右上角的 **「开发者模式」** 开关。
4. 点击左上角（或页面上方）的 **「加载已解压的扩展程序」**。
5. 在弹出的文件夹选择窗口里，选中整个 `imagegrab` 文件夹（能看到 `manifest.json` 的那一层），点「选择文件夹」。
6. 列表里出现 **「图提取 ImageGrab」**，并且开关是打开的，就说明安装成功了。

### 建议再做一步

点浏览器工具栏右侧的「拼图」图标（扩展程序），找到「图提取」，点旁边的图钉，把它固定到工具栏，以后更好找。

## 使用说明

1. 打开任意**商品详情页**  
   例如京东某个商品页：`https://item.jd.com/……`  
   （首页、搜索结果、购物车、店铺首页都不行，必须是单个商品的详情页。）

2. 看页面**右下角**  
   会出现一个悬浮按钮：**「获取图片」**。点它。

3. 等待几秒  
   插件会自动扫描页面上的商品图；如果图比较少，它还会自己往下滚一下，把懒加载的图片也捞出来。

4. 自动打开「图提取」预览页  
   新标签页里会列出找到的图片，每张都能看到缩略图和大概尺寸。

5. 按需勾选  
   - 可以改**文件名前缀**（默认是「商品图」）  
   - 可以用**最小尺寸**筛掉太小的图  
   - 支持**全选 / 反选**

6. 点 **「下载选中」**  
   进度条会显示下载进度。文件会保存到浏览器的**默认下载文件夹**，名字类似：

   ```
   商品图_001.png
   商品图_002.png
   商品图_003.png
   …
   ```

到这里就完成了。下次换一个商品详情页，重复上面步骤即可。

## 常见问题

### 1. 右下角没有「获取图片」按钮？

请依次检查：

- 是不是**商品详情页**？（列表页、首页、购物车不会出现按钮）
- 插件是否已启用？（到 `chrome://extensions` 看开关是否打开）
- 打开商品页之后，有没有**刷新一次页面**？
- 用的是不是淘宝 / 天猫 / 京东 / 拼多多商家版？其他网站暂不支持

### 2. 找到的图很少，或一张都没有？

很多详情页图片是「滚到下面才加载」的。可以先**自己把页面慢慢往下滚一遍**，再点「获取图片」。  
插件也会自动滚一次兜底，但手动滚一遍通常更稳。

### 3. 预览页里有的图显示「加载失败」？

部分图片网站有防盗链，**预览缩略图**可能看不了，但点下载时，插件会用自己的权限去取图，**多数情况下仍然能正常下载**。可以先勾选，再试下载。

### 4. 下载出来不是 PNG，而是原来的 jpg？

极少数图片不允许被读取转换。插件会自动改成「直接下载原图」，不影响你拿到文件，只是格式没转成 PNG。

### 5. 下载时一直弹「另存为」，要一张张选位置？

到浏览器设置里，关掉「下载前询问每个文件的保存位置」（不同浏览器措辞略有差别）。关掉后就会直接存到默认下载文件夹。

### 6. 以前能用，突然不好使了？

常见原因是文件夹被移动/改名了。请打开 `chrome://extensions`，把旧的删掉，再按「安装步骤」重新加载一次。

### 7. 可以在手机上用吗？

目前只支持电脑端的 Chrome / Edge（Chromium 内核，建议 Chrome 102 及以上）。手机浏览器一般装不了这类扩展。

## 权限说明

安装时浏览器可能会提示插件需要一些权限。含义如下（人话版）：

| 权限 | 用来干什么 | 会不会乱读我的东西？ |
| --- | --- | --- |
| 读取并修改你访问的网站上的数据（相关电商站点） | 在商品详情页显示按钮、扫描页面上的图片 | 只作用于淘宝/天猫/京东/拼多多等已声明的网站，不是随便哪个网页 |
| 下载文件 | 把勾选的图片保存到你的电脑 | 只在你点「下载选中」时才会下载 |
| 存储数据 | 临时记住这次提取到的图片列表，方便在预览页显示 | 数据存在本机浏览器里，用完可被覆盖/清理 |
| 访问图片相关域名（如淘宝/京东的图片服务器） | 把图片取下来并转成 PNG | 只为下载和转格式，不上传你的数据 |

**隐私承诺（简要）：**

- 不注册、不登录、不联网上传商品图  
- 图片转换与下载都在本机完成  
- 请仅用于个人学习与素材整理，并遵守各电商平台规则与图片版权要求
