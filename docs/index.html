产品介绍

商品图搬运，不该是体力活

详情页里的图片分散在不同模块，还常被懒加载藏起来。图提取把「找图、筛图、存图」压缩成一次点击。

图片分散、藏在懒加载里

主图、图文详情、SKU 图分散在不同容器，滚动后才加载。插件会扫描 <img>、srcset、data-src 与背景图，必要时自动滚动触发加载。

一张张右键另存太慢

详情页动辄二三十张图，手动保存要反复确认目录、改名。现在勾选后一次批量下载，自动排好序号。

格式不统一、还要逐张转换

原图可能是 jpg、webp，命名五花八门。插件在扩展内部用 OffscreenCanvas 统一转成 PNG，输出 商品图_001.png 这样的规范文件名。

它不是一个「下载整个网页」的粗暴工具：图提取只在商品详情页出现，只挑跟商品相关的图片， 默认丢弃图标、logo、1×1 像素和小于 100×100 的小图，再按分辨率从大到小排好，让你先看到真正能用的素材。

所有处理都在你自己的浏览器里完成——不登录、不上传、不经过任何服务器，商品图和页面信息不会离开本机。

核心功能

六件事，一次做完

从扫描到落盘，整条链路都在插件里闭环。

一键提取

自动扫描页面所有商品图，兼容懒加载属性；图片太少时自动滚屏兜底。

智能过滤

按 URL 特征与真实像素尺寸双重过滤，自动排除图标、logo、占位图和小图。

集中预览

在新标签页用响应式网格展示全部图片，附缩略图与真实尺寸，一眼判断可用性。

自由勾选

全选、反选、按尺寸筛选，默认全选再取消不要的，顺序与文件名实时对应。

统一 PNG

jpg / webp / gif 全部在扩展内转码为 PNG，跨域图片也能处理，自动补零编号。

批量下载

下载带实时进度与完成反馈，保存到浏览器默认下载目录，不弹一堆另存为窗口。

安装步骤

四步装好，一分钟上手

无需账号、无需构建工具，解压即可加载。

  1. 01

    解压插件包

    下载 imagegrab.zip 后解压到任意固定文件夹（比如 D:\extensions\imagegrab），之后不要删除或移动它。

  2. 02

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 并回车（Edge 用 edge://extensions）。

  3. 03

    打开开发者模式

    点右上角的「开发者模式」开关，让页面出现「加载已解压的扩展程序」按钮。

  4. 04

    加载已解压的扩展程序

    点「加载已解压的扩展程序」，选中解压后的文件夹；随后打开任意商品详情页，点右下角「获取图片」。

小提示

插件只在淘宝 / 天猫、京东、拼多多商家版的商品详情页出现；改完代码记得回扩展页点一次「刷新」。
